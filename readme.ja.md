**MONOPOLIC** は、伝説のアナログ・シンセサイザー **Korg Mono/Poly (1981)** のクラシックな4オシレーター構成にインスパイアされ、**CrystalMatrix (aka Paquini Balandra)** によって制作された **Korg drumlogue** 用のユーザー・シンセサイザーです。

**Plugdata** と **Heavylib** ライブラリを用いてビジュアルプログラミングで開発され、**hvcc (Heavy Compiler Collection)** によってネイティブC++へコンパイルされています。クロスモジュレーション（FM）、パルス幅変調（PWM）、レゾナント・フィルターを備えた4つのVCOの多彩なサウンドを、drumlogue の **USER** トラックへ直接もたらします。

---

## 🎛️ 主な特徴

* **4オシレーター構成 (`OSC 1` 〜 `OSC 4`):**
  * オリジナルの Mono/Poly の精神を受け継ぎ、波形選択可能な4つの独立したオシレーターを搭載しています（*Off、サイン波、三角波、ノコギリ波、パルス波*）。
  * 各オシレーターは **±3オクターブ（`-36` 〜 `+36` セミトーン）** の範囲で個別にピッチ調整が可能。さらに、OSC 2、3、4にはわずかなアナログ風のデチューン（固定ピッチのズレ）が施されており、重厚なベースや太いリード、ユニゾン風の質感を生み出します。
* **モジュレーション・セクション (`FM & PWM`):**
  * 専用のモジュレーター・オシレーター（`FMWAVE`、`FMFREQ`、`FMDEPTH`、`FMGAIN`）を搭載し、メタリックな音色やパーカッシブなサウンド、クロスモジュレーション効果を作成できます。
  * リアルタイムで調整可能なパルス幅変調（`PWM`）を搭載。
* **レゾナント・ローパスフィルター（約24dB/oct）:**
  * 2段階直列接続の `vcf~` フィルターを採用。カットオフ周波数（`CUTOFF`: 20 Hz 〜 16 kHz）、レゾナンス（`RES0`）、専用エンベロープ（`F.ENV`）を備えています。
* **ダイナミック・エンベロープ (`SELADSRS`):**
  * 4つのコントロール（`ATTACK`、`DECAY`、`SUSTAIN`、`RELEASE`）を1ブロックに集約。セレクターを切り替えることで、メニュー画面を煩雑にすることなくアンプ（VCA）とフィルター（VCF）の両方のエンベロープを編集できます。
* **インテリジェント・ルーティング・マトリクス (`MACROSEL`):**
  * 1つのマスターノブ（`MACRO`）と22ポジションのセレクター（`MACROSEL`）による集中コントロールシステム。各オシレーターの個別ミックスレベルやモジュレーションのセンド量を効率的に調整できます。

## 🧭 クイックリファレンスガイド

### エンベロープ・セレクター (`7. SELADSRS`)
* **`0`:** **アンプ・エンベロープ (AMP)** のみを編集します。
* **`1`:** **フィルター・エンベロープ (FILTER)** のみを編集します。
* **`2`:** **両方のエンベロープ (AMP + FILTER)** を同時に編集します。

### ターゲット・マトリクス (`5. MACROSEL`)
`MACROSEL` パラメーターを使用して、`MACRO` ノブで変更したい内部レベルを選択します：
* **`0`:** マスターゲイン / 全体出力 (`MAIN GAIN`)
* **`1` - `4`:** 各オシレーターの個別ミックス (`OSC 1`, `OSC 2`, `OSC 3`, `OSC 4`)
* **`5`:** ダイレクト音レベル (`DRY LEVEL`)
* **`6` - `13`:** PWMセクションへの個別センド (`PWM OSC 1` 〜 `OSC 4`)
* **`14` - `20`:** FMセクションへの個別センド (`FM OSC 1` 〜 `OSC 4`) およびウェットレベル (`WET LEVEL`)

## 📥 Korg drumlogue へのインストール方法

1. このリポジトリの [Releases](../../releases) セクションから **`monopolic.drmlgunit`** ファイルをダウンロードします。
2. USBケーブルで Korg drumlogue とパソコンを接続します。
3. **[PLAY]** ボタンを押しながら drumlogue の電源を入れ、**USB Storage Mode** で起動します。
4. ダウンロードした `monopolic.drmlgunit` ファイルを以下のフォルダ内にコピーします：
   ```text
   /Units/Synths/
   ```
5. パソコンから安全な取り外しを行ってドライブを取り出し、drumlogue を再起動します。
6. **USER** トラックを選択し、**SYNTH** エンジンから **Monopolic** を選びます。

## 🛠️ ソースコードからのビルド方法

Pure Data で元のパッチを確認・編集したい場合：

1. [Plugdata](https://plugdata.org)、[hvcc](https://github.com)、および [Korg logue-sdk](https://github.com) をインストールします。
2. Plugdata でソースファイル `.pd` を開いて `drumlogue` プラットフォーム向けにコンパイルするか、以下のコマンドを実行します：
   ```bash
   hvcc monopolic.pd -o ./build -n monopolic -g drumlogue
   ```
